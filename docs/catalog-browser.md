# 콘텐츠 검색·필터 패턴

## 목적과 기존 패턴

표시만 하던 아티클 카테고리와 외부 마켓으로 이동하던 템플릿 탭을 실제 목록 필터로 바꿉니다. 기존 카드, 정렬, 링크, 영상 팝업은 유지하고 세 페이지에 같은 조작 방식을 제공합니다.

## API

`CatalogBrowser`는 서버가 생성한 카드 배열을 `children`으로 받습니다. 공개된 제목·설명·분류만 `items`로 전달하며, 본문이나 서버 전용 데이터·비밀키는 전달하지 않습니다. 두 배열은 같은 순서이며 `items.id`는 고유해야 합니다.

| 속성 | 용도 / 기본값 |
| --- | --- |
| items | id, title, description, category, 선택적 marketplaces |
| children | items와 같은 순서의 카드 배열 |
| label | 아티클 / 무료 강의 / 템플릿 |
| listClassName | 기존 guide-list / lessons-grid / template-gallery |
| showMarketplaceFilter | 판매처 필터 표시, 기본 false |

## 상태와 동작

| 상태 | 표시와 동작 |
| --- | --- |
| 기본 | 전체 목록과 결과 수, 초기화 비활성 |
| 검색 중 | 입력 즉시 제목·설명·분류 검색; 템플릿은 판매처도 검색 |
| 필터 선택 | 버터색 배경과 검은 테두리; 검색어와 모든 조건을 AND로 결합 |
| Hover / Focus | 크림색 hover, 브라운 포커스 윤곽선 |
| 검색어 지우기 | 검색어만 지우고 입력란으로 초점 복귀 |
| 초기화 | 모든 조건을 지우고 입력란으로 초점 복귀 |
| 결과 없음 | 원인 안내와 전체 콘텐츠 보기 버튼 |
| 원본 콘텐츠 없음 | 목록 페이지의 기존 준비 중 안내; 아티클은 등록된 콘텐츠 없음 |

브라우저 내 동기 필터링이므로 네트워크 로딩 상태가 없습니다. 검색 결과 때문에 필터 항목 자체를 숨기지 않아 다른 조건으로 바로 바꿀 수 있습니다. 새로고침 시 기본 상태로 돌아갑니다.

## 디자인 토큰

기존 `--butter`, `--cream`, `--paper`, `--card`, `--foreground`, `--brown`, `--muted-foreground`, `--border`, `--radius-md`, `--radius-lg`, `--font-display`를 사용합니다. 필터는 여러 줄로 감싸지고 긴 이름도 줄바꿈하여 모바일 가로 넘침을 방지합니다.

## 접근성

- 검색 영역은 `<search>` 랜드마크, 입력란은 표시된 label과 연결합니다.
- 각 필터 그룹은 fieldset/legend, 선택 여부는 `aria-pressed`, 결과 연결은 `aria-controls`로 표현합니다.
- Tab으로 이동하고 Enter/Space로 버튼을 조작합니다. 클릭 영역은 최소 높이 44px입니다.
- 결과 수만 `<output>`의 암시적 status 역할로 알립니다. 입력마다 목록으로 초점을 강제 이동하지 않습니다.
- 카드 링크는 정적 HTML에도 존재합니다. JavaScript가 없으면 전체 목록과 사용 안내를 표시합니다.

## 사용 규칙

분류/판매처는 하드코딩하지 않고 실제 공개 데이터에서 추출합니다. 카드 본문·판매 링크·영상 재생 방식을 검색 컴포넌트에 중복 구현하지 않습니다. 검색어를 로그나 외부 API로 전송하지 않습니다.
