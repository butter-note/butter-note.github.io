# 회의록이 흩어지지 않는 팀 위키 만들기

회의록은 작성보다 다시 찾는 일이 더 중요합니다. 날짜별 문서를 쌓는 대신 회의의 목적과 다음 행동을 연결해보세요.

## 기본 속성

| 속성 | 용도 |
| --- | --- |
| 회의 일자 | 언제 진행했는지 기록 |
| 참석자 | 맥락을 물어볼 사람 확인 |
| 결정 사항 | 합의된 내용을 빠르게 확인 |
| 다음 행동 | 담당자와 마감일 연결 |

## 회의가 끝나면 확인하세요

- [ ] 결정 사항이 한 문장으로 정리되었나요?
- [ ] 모든 다음 행동에 담당자가 있나요?
- [ ] 관련 프로젝트와 연결했나요?
